# Stranger Things — Promotional Experience

Projeto front-end inspirado em **Stranger Things**, criado como conceito de site promocional para uma experiência temática.

## Objetivo

Construir uma página imersiva que utilizasse identidade visual, movimento e navegação para reproduzir a atmosfera da obra em uma experiência web.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- GSAP ScrollSmoother
- GSAP SplitText

## Destaques

- Experiência visual temática
- Animações acionadas durante o scroll
- Rolagem suavizada
- Animações tipográficas
- Seções de apresentação da experiência
- Seleção/apresentação de cidades
- Preloader e transições visuais

## Estrutura

```text
.
├── fontes/
├── imagens/

├── script.js
└── style.css
```

## Aprendizados

O projeto foi utilizado para estudar:

- animações coordenadas com GSAP;
- storytelling visual em páginas promocionais;
- experiência de navegação baseada em scroll;
- composição de interfaces imersivas;
- organização de recursos visuais e tipográficos.
